# 🏙️ Город решений

Веб-игра для исследования когнитивных искажений.

## 📁 Структура файлов

```
gorod-resheniy/
├── index.html          # Главная страница
├── css/
│   └── style.css       # Стили
├── js/
│   ├── data.js         # 60 вопросов + описания искажений
│   ├── game.js         # Логика игры и подсчёт результатов
│   └── ui.js           # Рендеринг интерфейса
└── README.md
```

## 🎮 Механика игры

- 6 районов × 10 вопросов = 60 ситуаций
- Каждый вопрос тестирует одно из 8 когнитивных искажений
- Прогресс сохраняется в localStorage
- После 60 ответов открывается экран результатов с radar-чартом

## 🧠 Когнитивные искажения в игре

| Искажение | Районы |
|-----------|--------|
| Избегание потерь | Финансовый, Торговый |
| Невозвратные затраты | Финансовый |
| Эффект якоря | Финансовый, Торговый, Когнитивный |
| Социальное влияние | Социальный, Торговый |
| Самоуверенность | Неопределённость, Когнитивный |
| Предвзятость подтверждения | Когнитивный |
| Ориентация на настоящее | Финансовый, Торговый, Время |
| Эффект статус-кво | Торговый, Когнитивный, Время |

## ⚙️ Технологии

- Чистый HTML + CSS + JavaScript (без зависимостей)
- SVG-карта города (встроена в HTML)
- localStorage для хранения прогресса
- Radar chart на SVG
